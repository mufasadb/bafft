# NPC Roll Tables for Draw Steel (bafft)

This JSON file (`npc-roll-tables.json`) contains highly specific, flavorful traits and details designed to spark the GM's imagination when generating NPCs for a heroic fantasy setting like MCDM's *Draw Steel*.

## Contents
The file provides extensive roll tables across the following dimensions:
- **occupations (150 entries):** Spanning various walks of life from the Underworld to Noble Courts.
- **looks (120 entries):** Evocative physical appearances and distinct smells.
- **voices (80 entries):** Specific vocal quirks and habits.
- **behaviours (100 entries):** Actionable tics and mannerisms visible in a scene.
- **flaws (80 entries):** Meaningful character flaws to complicate interactions.
- **helpReasons & refuseReasons (60 entries each):** Distinct motivations for why the NPC might aid or hinder the heroes.
- **hooks (80 entries) & secrets (60 entries):** Evocative one-sentence adventure seeds.
- **nameByAncestry:** Original names crafted according to the distinct cultural phonetics of the 12 *Draw Steel* ancestries (devil, dragonKnight, dwarf, wodeElf, highElf, hakaan, human, memonek, orc, polder, revenant, timeRaider).

## Note on Names
The ancestry names avoid direct copying from sourcebooks, instead adhering strictly to the phonetic guidelines provided for each ancestry's style (e.g., Sanskrit roots for Memonek, Old Persian for Hakaan, compound surnames for Polders).

## Usage
Simply load this JSON into your table-rolling service, pick one random entry from the required fields, and feed them into your LLM pipeline for prose generation.
